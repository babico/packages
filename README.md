# packages

Multi-platform package repository with GitHub Actions automation.

**Live index:** https://babico.github.io/packages/ — every indexed release with
its Linux / Windows / macOS installers, grouped by CPU architecture.

| App | APT (Linux) | Scoop (Windows) | Homebrew (macOS/Linux) |
|-----|-------------|-----------------|----------------------|
| [RustDesk](https://rustdesk.com) | amd64, arm64, armhf | amd64 | arm64, x86, amd64 |
| [Mattermost Desktop](https://mattermost.com) | amd64, arm64 | amd64 | arm64, x86, amd64 |
| [Tixati](https://tixati.com) | amd64, i386 | amd64 | amd64 (Linux only) |
| [GitHub CLI](https://cli.github.com) | amd64, i386, arm64, armhf | amd64 | arm64, x86, amd64 |
| [Apidog](https://apidog.com) | amd64 | amd64, x86 | arm64, x86, amd64 |

## APT (Linux)

### Setup

```bash
curl -fsSL https://babico.github.io/packages/apt-repo.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/personal-apt.gpg

echo "deb [signed-by=/usr/share/keyrings/personal-apt.gpg] \
  https://babico.github.io/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/personal-apt.list

sudo apt update
```

### Install

```bash
sudo apt install rustdesk mattermost-desktop tixati gh apidog
```

### Install specific version

```bash
sudo apt install rustdesk=1.4.5
sudo apt install gh=2.95.0
```

### Hold / downgrade

```bash
sudo apt-mark hold rustdesk
sudo apt install rustdesk=1.4.4
sudo apt-mark unhold rustdesk
```

### Unsigned fallback

```bash
echo "deb [trusted=yes] https://babico.github.io/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/personal-apt.list
```

## Repo structure

```
docs/                           # GitHub Pages (APT repo + landing page)
  index.html                    # generated release index (UI)
  dists/stable/                 # APT index (Packages, Release, signed)
  pool/main/{letter}/{app}/     # .deb files (gitignored by default)

.github/build/{product}/        # Build definitions
  config.yml                    # Product metadata
  deb-{arch}.yml                # DEB build targets
  dmg-{arch}.yml                # DMG build targets
  rpm.yml                       # RPM build target
  scoop.yml                     # Scoped asset rules (asset_ext, suffixes)
  scoop.json.tmpl               # Scoop manifest template
  brew.rb.tmpl                  # Homebrew formula template
  rpm.spec.tmpl                 # RPM spec template

scripts/
  build-all.sh                  # Orchestrator (detect → download → index → deploy)
  build-apt.sh                  # APT index generator (--multiversion)
  build-index.sh                # Release index UI (platform/CPU installers)
  yaml-get.py                   # YAML reader
  backfill-history.sh           # Upstream release + asset discovery
  backfill-debs.sh              # Budgeted historical .deb downloader
  verify.sh                     # Offline artifact / script self-check

bucket/                         # Scoop manifests (generated)
Formula/                        # Homebrew formulas (generated)
tracked/                        # Version + installer asset tracking

.github/workflows/update.yml    # Single CI workflow (every 6h, rebuild mode)
```

## How it works

```
.github/build/{product}/
        ↓
   build-all.sh
   ┌───────────────────────────────────────────┐
   │ 1. detect version (github API / scrape)   │
   │ 2. download .deb → docs/pool/             │
   │ 3. build scoop.json from template         │
   │ 4. build brew.rb from template            │
   │ 5. track version + per-OS installer URLs  │
   │ 6. apt index (dpkg-scanpackages           │
   │    --multiversion — keeps all versions)   │
   │ 7. generate release index UI              │
   │ 8. commit → push → deploy to Pages        │
   └───────────────────────────────────────────┘
```

Scheduled runs pass `rebuild`: downloads are skipped for unchanged versions,
but the signed APT index and the index UI are regenerated on every run.

## Index UI

`docs/index.html` is generated by `scripts/build-index.sh`. Each release row
lists installer chips grouped by **Linux / Windows / macOS** and CPU, with
copyable, version-pinned `apt` / `scoop` / `brew` commands. The page has a
global `/` search, platform filter, per-package filters, keyboard navigation,
visible focus states and reduced-motion support.

## Version history / backfill

`tracked/*.json` holds upstream releases with their release date, CPU list and
a per-platform `assets` array (`os`, `cpu`, `url`). Sources: GitHub releases API
(GitHub-hosted apps), directory listing (Tixati), and the `latest` artifact for
Apidog. A version is tracked **only when at least one installable artifact
exists** — a `.deb`, a Windows `.exe`/`.msi`, or a macOS `.dmg`/`.zip`. Releases
with no installer anywhere are skipped, so the index never advertises a version
you cannot install. `backfill-history.sh` deduplicates by version and keeps the
union of assets/architectures across runs.

Apidog only publishes `latest` URLs and its `.deb` is ~157 MB (over GitHub's
100 MiB git limit). It uses `ephemeral_pool: true`: the binary is downloaded
into `docs/pool/` on every CI run (never committed) so it is included in the
Pages artifact and can be served, and `publish_archs: amd64` keeps the site
under the 1 GB limit. Its `assets` are generated from the build configs so the
index can still show every platform.

```bash
bash scripts/backfill-history.sh   # discover versions + installer assets
bash scripts/backfill-debs.sh      # budgeted historical .deb downloader
git add -f docs/pool/              # pool/*.deb is gitignored — force-add to publish
bash scripts/verify.sh             # offline self-check
```

`backfill-debs.sh` is budgeted (`BUDGET_MB`, `MAX_GH`, `MAX_RUSTDESK`,
`MAX_TIXATI`) to stay under the GitHub Pages size limit. Mattermost is skipped
(~98 MB per package, newer ones over 100 MiB). CI rebuilds and signs
`docs/dists/` from the complete pool on every run.

## Adding a new app

Create a folder under `.github/build/` with:

```
.github/build/my-app/
  config.yml          # name, display, homepage, source type
  deb-amd64.yml       # download URL, suffix, pool_name
  scoop.yml           # asset_ext (exe|msi|zip) for github sources
  scoop.json.tmpl     # ${VERSION}, ${SHA256} placeholders
  brew.rb.tmpl        # ${VERSION}, ${MAC_ARM_URL}, ${LINUX_AMD64_SHA256}, etc.
```

**config.yml — GitHub-hosted app:**

```yaml
name: my-app
display: My App
description: Description
homepage: https://example.com
source: github
repo: owner/repo
pool_letter: m
version_prefix: v
```

**config.yml — directory listing source (Tixati-style):**

```yaml
name: my-app
source: http_listing
listing_url: https://downloads.example.com/
version_match: "my-app-([0-9.]+)-amd64\\.deb"
```

**config.yml — zip download source (Apidog-style):**

```yaml
name: my-app
source: zip_download
extract_regex: "my-app_([0-9.]+)_"
# Large binaries that must not be committed to git:
ephemeral_pool: true      # download into Pages pool on every CI run
publish_archs: amd64      # keep the published site under 1 GB
```

`scoop.yml` should set `asset_ext` for GitHub-hosted apps so the asset picker
chooses the Windows file the manifest actually expects (`zip`, `msi` or `exe`).

For sources without versioned URLs, installers are inferred from the build
configs and stored as `assets` on each tracked version, which is what the index
UI renders.

**deb-amd64.yml:**

```yaml
format: deb
arch: amd64
suffix: amd64.deb
download_url: "https://example.com/downloads/${VERSION}/my-app_${VERSION}_amd64.deb"
pool_name: "my-app_${VERSION}_amd64.deb"
```

**Template placeholders:**

| Template | Placeholders |
|----------|-------------|
| `scoop.json.tmpl` | `${VERSION}`, `${SHA256}` |
| `brew.rb.tmpl` | `${VERSION}`, `${MAC_ARM_URL}`, `${MAC_ARM_SHA256}`, `${MAC_X86_URL}`, `${MAC_X86_SHA256}`, `${LINUX_ARM_URL}`, `${LINUX_ARM_SHA256}`, `${LINUX_AMD64_URL}`, `${LINUX_AMD64_SHA256}` |
| `rpm.spec.tmpl` | `__VERSION__`, `__CHANGELOG__` |
